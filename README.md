# Санчоус — магазин соусов

Лендинг + Telegram-бот в одном репозитории. Бот сам раздаёт сайт и открывает
его как Telegram Mini App.

## Что внутри

```
index.html            страница магазина
css/style.css         вёрстка по макету
css/ui.css            корзина, избранное, карточка товара
js/main.js            логика магазина + интеграция с Telegram
img/                  фотографии, логотип, иконки приложения
manifest.webmanifest  установка как приложение (PWA)
sw.js                 офлайн-кэш
main.py               бот + веб-сервер (только стандартная библиотека Python)
```

## Возможности

**Сайт**
- каталог из 4 соусов, на телефоне — по 2 карточки в ряд;
- корзина: первое нажатие добавляет товар, дальше появляется «− 1 +»;
  минус до нуля возвращает кнопку «В корзину»;
- кнопка корзины в шапке видна всегда, со счётчиком;
- панель корзины со списком, количеством, суммой и оформлением заказа;
- избранное — сердечко у каждого соуса, отдельная вкладка в панели;
- карточка товара: крупное фото, состав, объём, срок хранения, с чем есть;
- корзина и избранное сохраняются между визитами;
- ставится как приложение на телефон (PWA) и работает офлайн.

**Бот**
- раздаёт сайт из этой же папки;
- `/start` — кнопка «Открыть магазин» (Mini App) и ссылка на сайт;
- `/catalog`, `/delivery`, `/help`;
- принимает заказ из мини-приложения и присылает состав заказа.

## Переменные окружения

| Переменная   | Обязательно | Зачем |
|--------------|-------------|-------|
| `BOT_TOKEN`  | да          | токен от @BotFather |
| `PUBLIC_URL` | да          | публичный **https**-адрес сайта; без него Telegram не даст открыть Mini App |
| `PORT`       | нет         | порт веб-сервера, по умолчанию `8080` |
| `ADMIN_ID`   | нет         | чат, куда дублировать заказы |

Токен нигде в коде не хранится — только в настройках хостинга.
Шаблон значений: `.env.example`.

## Запуск

Зависимостей нет, нужен только Python 3.8+.

```bash
BOT_TOKEN=... PUBLIC_URL=https://ваш-адрес PORT=8080 python main.py
```

Локально без бота — просто посмотреть сайт:

```bash
python -m http.server 8777
```

## Хостинг

Главный файл — `main.py`. После деплоя пропишите `PUBLIC_URL` равным адресу,
который выдал хостинг, и перезапустите бота: тогда кнопка меню и кнопка
«Открыть магазин» начнут открывать сайт внутри Telegram.
